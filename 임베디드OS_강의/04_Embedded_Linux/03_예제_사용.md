## 예제 1. 루트 파일시스템 탐색과 시스템 확인 (20분)

부팅 후(QEMU 또는 보드) 아래를 실행합니다.

```sh
cat /etc/os-release
uname -a
ps aux                 # 프로세스 목록
mount | head           # 파일시스템 마운트
dmesg | grep -i mmc    # 스토리지 인식
top                    # CPU/메모리
ip addr                # 네트워크 (있을 때)
```

**학습 포인트**: 모든 것이 '파일'로 보이는 Unix 철학 — 디바이스는 `/dev`, 제어는 `/proc`, `/sys`.

## 예제 2. 크로스 컴파일 앱 배포 (30분)

호스트에서:
```bash
cat > hello.c <<'EOF'
#include <stdio.h>
#include <unistd.h>
int main(void) {
    for (int i = 0; i < 5; i++) {
        printf("hello embedded linux %d (pid=%d)\n", i, getpid());
        sleep(1);
    }
    return 0;
}
EOF

./output/host/bin/arm-linux-gnueabihf-gcc -O2 hello.c -o hello
```

배포 (QEMU SD rootfs의 경우):
```bash
# 루트fs를 마운트 후 복사 (예시)
sudo mount -o loop output/images/rootfs.ext4 /mnt
sudo cp hello /mnt/usr/bin/
sudo umount /mnt
```

보드에서:
```sh
chmod +x /usr/bin/hello && hello
```

### 동적 링크 주의
- 기본은 glibc/musl 동적 링크 → 타깃에 동일 라이브러리 필요
- `-static`으로 정적 링크하면 단독 실행 가능 (크기 증가)
- 실무: 패키지 관리자(opkg/apt) 또는 OTA 서버로 배포

## 예제 3. systemd 서비스 등록 (30분)

`hello.service`:
```ini
[Unit]
Description=Hello Service
After=network.target

[Service]
ExecStart=/usr/bin/hello
Restart=on-failure
RestartSec=2

[Install]
WantedBy=multi-user.target
```

배포·실행:
```sh
cp hello.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now hello.service
systemctl status hello.service
journalctl -u hello.service -f
```

크래시 시 자동 재시작(`Restart=on-failure`) 동작 확인:
```sh
systemctl kill -s SIGKILL hello.service
journalctl -u hello.service | tail
```

> BusyBox init 기반 이미지에서는 `/etc/inittab` + 스크립트 방식으로 대체.

## 예제 4. GPIO/LED (sysfs vs libgpiod) (20분)

구 방식(sysfs) — 일부 이미지에서 제거됨:
```sh
echo 496 > /sys/class/gpio/export      # 칩/보드에 따라 핀 번호 상이
echo out > /sys/class/gpio/gpio496/direction
echo 1 > /sys/class/gpio/gpio496/value
```

현대 방식(**libgpiod**, 커널 메인스트림):
```sh
gpioinfo                      # 칩·라인 목록
gpioset gpiochip0 4=1         # 높음
gpiomon gpiochip0 4           # 이벤트 감시
```

C 코드는 `libgpiod` API (`gpiod_chip_open`, `gpiod_line_set_value`) 사용.

## 예제 5. 실시간성 확인과 PREEMPT_RT (20분)

현재 커널의 프리옵트 모드 확인:
```sh
zcat /proc/config.gz | grep PREEMPT      # 또는 /boot/config-$(uname -r)
uname -a                                  # '-rt' 빌드 여부 표시
```

간단한 지연 측정 (cyclictest, `rt-tests` 패키지):
```sh
cyclictest -m -p80 -l10000 -i200 -h400
# 최대/평균 지연(us) 출력. 기본 커널: 수백~수천 us
# PREEMPT_RT 빌드: 수십 us대로 개선 기대
```

PREEMPT_RT 활성화 경로(개념):
1. 해당 커널 버전이 메인라인 PREEMPT_RT를 포함하는지 확인
2. 아니면 RT-Preempt 패치 적용 빌드
3. `CONFIG_PREEMPT_RT=y`, `CONFIG_HIGH_RES_TIMERS=y`
4. 실시간 태스크: `chrt -f 80 ./my_rt_app` 또는 cgroups 설정

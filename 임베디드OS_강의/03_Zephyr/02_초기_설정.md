# Zephyr — 초기 설정

> 5일차 실습 준비 (90분) · 대상: Windows 10/11 + WSL2(권장) 또는 Linux 호스트 · 보드: nRF52840 DK / QEMU

> Zephyr 공식 최신 절차: https://docs.zephyrproject.org/latest/develop/getting_started/

---

## 1. 사전 요구사항

| 항목 | 내용 |
|---|---|
| OS | Linux(권장) 또는 Windows + **WSL2** |
| 패키지 | cmake, ninja, python3(venv), dtc(device-tree-compiler), gcc |
| 하드웨어 | nRF52840 DK (없으면 **QEMU**로 전체 실습 가능) |
| 여유 공간 | ~10GB (소스 + SDK + 빌드) |

Ubuntu/WSL2 기준:
```bash
sudo apt update
sudo apt install --no-install-recommends git cmake ninja-build gperf \
  ccache dfu-util device-tree-compiler python3-dev python3-pip \
  python3-venv xz-utils file make gcc gcc-multilib g++-multilib
```

---

## 2. Zephyr SDK 설치

```bash
wget https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v0.16.8/zephyr-sdk-0.16.8_linux-x86_64.tar.xz
tar xf zephyr-sdk-0.16.8_linux-x86_64.tar.xz
cd zephyr-sdk-0.16.8
./setup.sh          # 모든 툴체인 + udev 규칙(관리자)
```

> 버전은 문서에서 최신 안정 버전 확인 후 교체하세요.

---

## 3. 워크스페이스 준비 (West)

```bash
mkdir -p ~/zephyrproject && cd ~/zephyrproject
python3 -m venv .venv
source .venv/bin/activate
pip install west
west init https://github.com/zephyrproject-rtos/zephyr
west update          # 수 분 소요 (서브모듈 다운로드)
west zephyr-export
pip install -r ~/zephyrproject/zephyr/scripts/requirements.txt
```

---

## 4. 첫 빌드 — QEMU (보드 없이)

```bash
cd ~/zephyrproject/zephyr
west build -p -b qemu_x86 samples/hello_world
west build -t run
```

기대 출력:
```
*** Booting Zephyr OS build zephyr-v3.x.x ***
Hello World! qemu_x86
```

Cortex-M 시뮬레이션:
```bash
west build -p -b qemu_cortex_m3 samples/hello_world
west build -t run
```

---

## 5. 실제 보드 빌드·플래시 (nRF52840 DK)

```bash
west build -p -b nrf52840dk/nrf52840 samples/basic/blinky
west flash          # J-Link/USB-Serial로 플래시
```

LED 점멸 확인. `west build -t menuconfig`로 구성 메뉴 진입 가능.

## 6. 아웃 오브 트리 앱 프로젝트 생성

```bash
mkdir -p ~/my_app/src && cd ~/my_app
```

**CMakeLists.txt**
```cmake
cmake_minimum_required(VERSION 3.20.0)
find_package(Zephyr REQUIRED HINTS $ENV{ZEPHYR_BASE})
project(blinky_app)
target_sources(app PRIVATE src/main.c)
```

**prj.conf**
```
CONFIG_GPIO=y
```

**src/main.c**
```c
#include <zephyr/kernel.h>
#include <zephyr/drivers/gpio.h>

static const struct gpio_dt_spec led =
    GPIO_DT_SPEC_GET(DT_ALIAS(led0), gpios);

int main(void)
{
    if (!device_is_ready(led.port)) return -1;
    gpio_pin_configure_dt(&led, GPIO_OUTPUT_ACTIVE);

    while (1) {
        gpio_pin_toggle_dt(&led);
        k_msleep(500);
    }
}
```

빌드:
```bash
west build -b nrf52840dk/nrf52840 .        # 또는 qemu_cortex_m3
```

> `DT_ALIAS(led0)`는 **Device Tree**가 허용하는 별칭. 보드를 바꿔도 main.c 불변.

## 7. 문제 해결

| 증상 | 대처 |
|---|---|
| `west: command not found` | 가상환경 활성화 여부 확인 (`source .venv/bin/activate`) |
| `CMake Error: toolchain` | SDK 경로: `export ZEPHYR_SDK_INSTALL_DIR=~/zephyr-sdk-0.16.8` |
| `dfu-util` / flash 실패 | 보드 부트로더 모드 진입, udev 규칙(`setup.sh` 재실행) |
| Kconfig 경고 메시지 | `west build -t menuconfig`에서 해당 옵션 활성화 |

## 예제 1. Device Tree overlay로 핀 재배정 (30분)

블링키 예제에서 LED 핀이 다른 보드에 있을 때 C 코드를 고치지 않고 overlay로 해결합니다.

`boards/nrf52840dk_nrf52840.overlay`:
```dts
/ {
    aliases {
        led0 = &my_led;
    };
};

&gpio0 {
    my_led: led_0 {
        gpios = <&gpio0 13 GPIO_ACTIVE_LOW>;   /* P0.13 */
        label = "my custom led";
    };
};
```

빌드:
```bash
west build -p -b nrf52840dk/nrf52840 .
```

`main.c`는 그대로이고 Device Tree만 바뀐 것을 확인.

## 예제 2. Kconfig로 기능 켜기/끄기 (20분)

**prj.conf** 변경 예시 (버튼 인터럽트):
```
CONFIG_GPIO=y
CONFIG_SERIAL=y
CONFIG_UART_INTERRUPT_DRIVEN=y
CONFIG_APP_LOG_LEVEL_INF=y
```

내 매크로 정의도 가능:
```
CONFIG_APP_SAMPLE_NAME="lab5"
```
→ `main.c`에서 `#ifdef CONFIG_APP_SAMPLE_NAME`으로 사용.

> 실무 팁: `.config`는 커밋하지 말고, 필요한 최소 옵션만 `prj.conf`에 기록. 디펜던시는 Kconfig가 자동 해석.

## 예제 3. 디바이스 드라이버 API로 버튼 인터럽트 (30분)

```c
#include <zephyr/kernel.h>
#include <zephyr/drivers/gpio.h>

static const struct gpio_dt_spec btn =
    GPIO_DT_SPEC_GET(DT_ALIAS(sw0), gpios);
static struct gpio_callback btn_cb_data;

static void button_pressed(const struct device *dev,
                           struct gpio_callback *cb, uint32_t pins)
{
    printk("Button pressed!\n");     /* 짧게! */
}

int main(void)
{
    if (!device_is_ready(btn.port)) return -1;
    gpio_pin_configure_dt(&btn, GPIO_INPUT);
    gpio_pin_interrupt_configure_dt(&btn, GPIO_INT_EDGE_TO_ACTIVE);
    gpio_init_callback(&btn_cb_data, button_pressed, BIT(btn.pin));
    gpio_add_callback(btn.port, &btn_cb_data);
    ...
}
```

## 예제 4. 센서 드라이버 (bme280) (20분)

I2C 센서가 연결된 경우 overlay:
```dts
&i2c0 {
    bme280@76 {
        compatible = "bosch,bme280";
        reg = <0x76>;
        label = "BME280";
    };
};
```

`prj.conf`:
```
CONFIG_I2C=y
CONFIG_SENSOR=y
CONFIG_BME280=y
```

`main.c`:
```c
#include <zephyr/drivers/sensor.h>

const struct device *dev = DEVICE_DT_GET(DT_NODELABEL(bme280));
struct sensor_value temp, press;

while (1) {
    sensor_sample_fetch(dev);
    sensor_channel_get(dev, SENSOR_CHAN_AMBIENT_TEMP, &temp);
    sensor_channel_get(dev, SENSOR_CHAN_PRESS, &press);
    printk("T=%d.%02d C  P=%d.%02d kPa\n",
           temp.val1, temp.val2, press.val1, press.val2);
    k_sleep(K_MSEC(1000));
}
```

> `samples/sensor/bme280` 예제 디렉터리가 이미 있으므로 참고 빌드도 가능.

## 예제 5. BLE 스캐너 (20분)

`prj.conf`:
```
CONFIG_BT=y
CONFIG_BT_CENTRAL=y
CONFIG_BT_MAX_CONN=1
CONFIG_BT_LOG_LEVEL_INF=y
```

`main.c` (핵심):
```c
#include <zephyr/bluetooth/bluetooth.h>
#include <zephyr/bluetooth/hci.h>

static void scan_found(const bt_addr_le_t *addr, int8_t rssi,
                       uint8_t type, struct net_buf_simple *ad)
{
    char addr_str[BT_ADDR_LE_STR_LEN];
    bt_addr_le_to_str(addr, addr_str, sizeof(addr_str));
    printk("Found device %s (rssi %d)\n", addr_str, rssi);
}

int main(void)
{
    struct bt_le_scan_param scan_param = {
        .type       = BT_LE_SCAN_TYPE_PASSIVE,
        .options    = BT_LE_SCAN_OPT_NONE,
        .interval   = BT_GAP_SCAN_FAST_INTERVAL,
        .window     = BT_GAP_SCAN_FAST_WINDOW,
    };
    bt_enable(NULL);
    bt_le_scan_start(&scan_param, scan_found);
    ...
}
```

실제 디바이스(스마트폰 광고 등)가 스캔되는 것을 확인하세요.

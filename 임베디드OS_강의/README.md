## 1. 강의 개요

| 항목 | 내용 |
|---|---|
| 교육 과정명 | 임베디드 운영체제 이해와 실습 |
| 기간 | 2주 (10일 기준, 일 4~5시간) |
| 대상 | 임베디드 SW 개발자, 전공 학생, 하드웨어 엔지니어 |
| 선수 지식 | C 언어 기초, 마이크로컨트롤러 기본 동작 |
| 실습 도구 | STM32CubeIDE, ESP32 Arduino/IDF, Zephyr West, Buildroot, QEMU 등 |

### 학습 목표

1. 임베디드 시스템에서 사용하는 6가지 소프트웨어 실행 환경의 **구조·특징·장단점**을 설명할 수 있다.
2. **프로젝트 요구사항**(실시간성, 안전 인증, 비용, 연산 성능)에 따라 적절한 OS를 선택할 수 있다.
3. 각 OS의 **개발 환경을 초기 설정**하고, 대표 예제를 빌드·실행해 볼 수 있다.
4. 각 OS의 대표 적용 사례를 제품·산업 분야와 연결할 수 있다.

## 4. 학습 사용법

1. **1일차**: `00_전체_오리엔테이션`의 3개 파일을 순서대로 읽고, 용어를 정리합니다.
2. **분야별 학습일**: 해당 디렉토리의 파일을 아래 순서로 학습합니다.
   - `01_개념...md` — 이론 정리 (강의 노트)
   - `02_초기_설정...md` — 개발 환경 설치·설정 단계별 절차
   - `03_예제_사용...md` — 코드 예제를 따라 만들고 실행
   - `0n_복습_퀴즈...md` — 개념 확인 (답안은 각 파일 하단)
3. **9~10일차**: `07_종합_및_평가`의 비교표·워크시트·기말 평가로 마무리합니다.
4. **보충(자율)**: `08_임베디드_AI/01_최신_임베디드_AI_포지션.md` — 최근 MCU·엣지 AI 동향과 OS 포지션 정리.

## 6. 참고 사항 (강사 노트)

- 원본 영상 수치(4 ~ 9KB, 20 ~ 50KB, 2억 3천만 대 등)는 **대략적 수치**이며 설정·버전·시점에 따라 달라집니다.
- "안전 인증 산출물 제공"은 OS 자체의 인증을 뜻하며, **최종 제품 인증은 별도**로 받아야 합니다.
- Linux 실시간성은 `PREEMPT_RT` 패치가 메인라인에 통합되는 흐름이므로 최신 커널 기준으로 다시 확인하세요.
- VxWorks·QNX는 상용 라이선스가 필요하므로 수업에서는 QEMU/평가판 환경 또는 영상·문서 시연으로 대체할 수 있습니다.

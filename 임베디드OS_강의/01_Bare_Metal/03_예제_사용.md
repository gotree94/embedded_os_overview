# Bare Metal — 예제 사용

> 2일차 실습 (120분) · 총 4단계: LED → 논블로킹 UART → 센서 상태머신 → 협력형 스케줄러

---

## 예제 1. Super Loop LED 토글 (10분)

`main.c`의 `while(1)`을 다음으로 교체합니다.

```c
while (1)
{
    HAL_GPIO_TogglePin(GPIOD, GPIO_PIN_12);
    HAL_Delay(500);   // Busy-wait 지연 (나중에 타이머로 개선)
}
```

**관찰 포인트**: `HAL_Delay`는 내부적으로 SysTick을 보며 루프를 막습니다. Super Loop에서 '기다리는 것'의 비용을 체감하세요.

## 예제 2. 인터럽트 + 플래그 패턴 (20분)

버튼 인터럽트로 LED를 제어하되, **ISR에서는 플래그만 세팅**합니다.

```c
/* main.c */
volatile uint32_t g_button_evt = 0;

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == GPIO_PIN_0)
        g_button_evt = 1;                 /* ISR은 짧게 */
}

while (1)
{
    if (g_button_evt) {
        g_button_evt = 0;
        HAL_GPIO_TogglePin(GPIOD, GPIO_PIN_12);
    }
}
```

**원칙**: ISR에서 무거운 처리(_printf, 많은 계산)를 하면 인터럽트 지연·중첩 문제가 생깁니다.

## 예제 3. 논블로킹 UART 수신 (30분)

수신 인터럽트로 바이트를 모으고, 라인이 완성되면 메인 루프에서 처리합니다.

```c
#define RX_MAX 64
volatile uint8_t  rx_buf;
volatile char     line[RX_MAX];
volatile uint16_t line_len = 0;
volatile uint8_t  line_ready = 0;

void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if (huart->Instance == USART2) {
        if (rx_buf == '\n' && !line_ready) {
            line[line_len] = '\0';
            line_ready = 1;
        } else if (line_len < RX_MAX - 1) {
            line[line_len++] = (char)rx_buf;
        }
        HAL_UART_Receive_IT(&huart2, (uint8_t *)&rx_buf, 1);  // 재무장
    }
}

/* main 초기화 */
HAL_UART_Receive_IT(&huart2, (uint8_t *)&rx_buf, 1);

/* while(1) 안 */
if (line_ready) {
    printf("got: %s\n", (const char *)line);   // 실제 제품에서는 UART로 출력
    line_len = 0;
    line_ready = 0;
}
```

이것이 **Non-blocking 설계**의 기본 패턴입니다. 루프는 절대 멈추지 않습니다.

## 예제 4. 센서 + 상태 머신 (40분)

가상의 온도 센서(ADC)를 읽어 3단계 상태 머신으로 동작하는 예제입니다.

```c
typedef enum { ST_INIT, ST_NORMAL, ST_ALERT, ST_FAULT } state_t;

static state_t  state = ST_INIT;
static uint32_t last_sample_tick = 0;

uint16_t read_temp_raw(void);        // ADC 소프트웨어 시작-변환-대기 없이
                                    // (DMA 또는 "변환 시작 → 다음 루프에서 결과 확인" 방식)
int temp_valid(uint16_t raw) { return raw != 0 && raw < 4095; }

void update_state_machine(void)
{
    uint32_t now = HAL_GetTick();

    switch (state) {
    case ST_INIT:
        if (now - last_sample_tick >= 100) {
            last_sample_tick = now;
            uint16_t raw = read_temp_raw();
            if (temp_valid(raw)) state = ST_NORMAL;
        }
        break;

    case ST_NORMAL: {
        uint16_t raw = read_temp_raw();
        float t = raw * 3.3f / 4095.0f * 100.0f;   // 예시 변환
        if (t > 60.0f) state = ST_ALERT;
        else if (!temp_valid(raw)) state = ST_FAULT;
        break;
    }
    case ST_ALERT:
        /* 경고 LED 점멸 + 사용자 정의 동작 */
        HAL_GPIO_TogglePin(GPIOD, GPIO_PIN_13);
        HAL_Delay(100);              // 주의: 여기서 멈추면 다른 기능 지연!
        break;

    case ST_FAULT:
        /* 안전 출력 */
        HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12 | GPIO_PIN_13 | GPIO_PIN_14, GPIO_PIN_SET);
        break;
    }
}

/* while(1) */
read_sensors();            // ADC 소스 갱신
update_state_machine();    // 위 함수
drive_outputs();           // 상태에 따른 출력
```

**토의 포인트**: `ST_ALERT`의 `HAL_Delay(100)`은 Super Loop 전체를 멈춥니다. → 다음 예제에서 해결.

## 예제 5. 협력형 스케줄러 (20분)

각 작업이 스스로 시간을 쪼개 양보하는 미니 스케줄러입니다.

```c
typedef struct {
    uint32_t period_ms;
    uint32_t last_ms;
    void   (*fn)(void);
} sched_t;

static void job_led(void)    { HAL_GPIO_TogglePin(GPIOD, GPIO_PIN_12); }
static void job_sensor(void) { read_sensors(); update_state_machine(); }
static void job_output(void) { drive_outputs(); }

sched_t jobs[] = {
    { 500, 0, job_led    },
    {  10, 0, job_sensor },
    {  10, 0, job_output },
};

while (1)
{
    uint32_t now = HAL_GetTick();
    for (int i = 0; i < 3; i++) {
        if (now - jobs[i].last_ms >= jobs[i].period_ms) {
            jobs[i].last_ms = now;
            jobs[i].fn();        // 각 작업은 짧게 끝내야 함
        }
    }
    /* 유휴 시간: 저전력 진입 등 */
}
```

여기서 한 단계 더 나가면 **선점형 RTOS(FreeRTOS)**입니다. → `02_FreeRTOS/` 참고.

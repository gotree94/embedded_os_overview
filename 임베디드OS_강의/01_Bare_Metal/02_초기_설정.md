# Bare Metal — 초기 설정

> 2일차 실습 준비 (60분) · 대상 보드: STM32F4 Discovery / Nucleo-F401RE (HBE Combo3 등 대체 가능)

---

## 1. 필요한 것

| 항목 | 내용 |
|---|---|
| 보드 | STM32F4 Discovery (STM32F407VG) 또는 Nucleo-F401RE |
| 케이블 | Micro-USB 또는 Mini-USB (보드 종류에 따라) |
| IDE | STM32CubeIDE (무료, 권장) 또는 VS Code + arm-none-eabi-gcc |
| 문서 | 보드의 데이터시트·레퍼런스 매뉴얼(RM), 칩의 Datasheet |

> HBE Combo3 보드를 쓰는 경우 `새 폴더 (5)\HBE\HBE-Combo3_*` 자료의 CH2 환경 설정을 참고하세요.

---

## 2. STM32CubeIDE 설치

1. STM32CubeIDE 다운로드: https://www.st.com/en/development-tools/stm32cubeide.html (무료, 계정 등록)
2. 설치 옵션은 기본값(하드웨어 추적 디버거 포함) 유지.
3. 설치 후 **Help → Software Updates**에서 최신 패키지 확인.
4. STM32Cube MCU 패키지(F4 시리즈) 설치 여부 확인: **Help → Manage Embedded Software Packages**

---

## 3. 첫 프로젝트 생성 (CubeMX 연동)

1. **File → New → STM32 Project** → 보드 선택 (예: STM32F407VG)
2. 칩이 탐지되면 프로젝트명 입력 (예: `day2_baremetal_blink`)
3. Perspective 전환: **Default (CubeMX)** → 상단 Pinout & Configuration
4. 최소 설정:
   - **SYS → Debug**: Serial Wire
   - **RCC → High Speed Clock (HSE)**: Crystal/Ceramic Resonator (보드 종류에 따라)
   - **GPIO**: LED 연결 핀(예: PD12~15 on F4 Discovery) → Output
   - **TIM2** (선택): 1 ms 틱을 위한 Base Time
5. **Project Manager → Toolchain/IDE**: STM32CubeIDE, Generate peripheral initialization as pair of .c/.h
6. **GENERATE CODE**

> 이 단계에서 생성되는 `Core/Src/main.c`, `Core/Src/stm32f4xx_hal_msp.c` 등이 Bare Metal 프로젝트 골격이 됩니다.

## 4. 코드 구조 이해 (생성 직후)

```
day2_baremetal_blink/
├── Core/
│   ├── Inc/
│   │   ├── main.h
│   │   ├── stm32f4xx_hal.h        # HAL 헤더
│   │   └── stm32f4xx_it.h          # 인터럽트 핸들러 선언
│   └── Src/
│       ├── main.c                  # 여기서 while(1)을 작성
│       ├── stm32f4xx_it.c          # ISR 본체
│       └── system_stm32f4xx.c      # 시스템 클럭 초기화
├── Drivers/                        # CMSIS + HAL 라이브러리
└── STM32F407VGTx_FLASH.ld          # 링커 스크립트 (플래시 배치)
```

## 5. HAL을 쓸 것인가, 레지스터를 직접 쓸 것인가

| 방식 | 장점 | 단점 | 학습 목적 |
|---|---|---|---|
| HAL (`HAL_GPIO_TogglePin`) | 빠른 개발, 이식성 | 오버헤드, 내부 동작 불투명 | 실무 투입 속도 |
| 레지스터 직접 (`GPIOx->ODR`) | 오버헤드 0, 하드웨어 이해 | 칩 종속 | 이번 과정의 'Bare Metal 정신' |

이번 강의에서는 **HAL로 시작하고, 핵심 부분은 레지스터 직접 접근도 경험**합니다.

레지스터 직접 LED 토글 예시:
```c
RCC->AHB1ENR |= RCC_AHB1ENR_GPIODEN;          // GPIOD 클럭 인가
GPIOD->MODER &= ~(0x3U << (2 * 12));          // PD12 출력 모드
GPIOD->MODER |=  (0x1U << (2 * 12));
GPIOD->ODR   ^=  (1U << 12);                  // 토글
```

## 6. 빌드·플래시·디버그

1. **Build** (Ctrl+B): 컴파일 에러·경고 확인
2. **Run** (F11): ST-LINK으로 플래시 후 디버그 세션 시작
3. LED가 1초 주기로 점멸하면 성공
4. **Window → Show View → Live Expressions** 또는 디버그 뷰에서 레지스터 값 확인

---

## 7. 문제 발생 시 대처

| 증상 | 확인 |
|---|---|
| 디버거 인식 실패 | ST-LINK 펌웨어 업데이트(Help → ST-LINK/Firmware upgrade), USB 케이블 데이터선 여부 |
| 클럭 오류 | RCC 설정과 실제 보드의 크리스탈 주파수 불일치 |
| LED 불점멸 | 핀 번호/포트 확인, GPIO 클럭 인가 누락 |
| HardFault | 스택 크기·링커 스크립트, 배열 오버플로 확인 |

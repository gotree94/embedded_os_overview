# VxWorks — 개념과 안전 인증

> 7일차 이론 (60분) · 상용 임무 필수 RTOS

---

## 1. 개념

- 1987년 **Wind River Systems** 출시. **상용 임무 필수(Mission-Critical) RTOS 시장의 선두**.
- 고성능 **모놀리식 실시간 커널** 구조. 오류가 허용되지 않는 환경 대상.
- 2009년 인텔 인수 → 2018년 TPG Capital에 매각, 현재 독립 벤더.

```
애플리케이션 (임무 소프트웨어)
VxWorks 커널 (스케줄링, 파일시스템, 네트워크, 드라이버)   ← 모놀리식
하드웨어 (Rad-hard MCU, 프로세서, SoC)
```

---

## 2. 핵심 특징

- **Hard Real-Time**, 마이크로초급 지연, 최소 타이밍 지터
- 사전 패키징된 **안전 인증 산출물** 제공
  - **DO-178C**: 상업용 항공전자
  - **IEC 61508**: 산업 자동화
  - **ISO 26262**: 자동차 기능안전
- 고급 **메모리 보호**(MPU/MMU 기반, 프로세스/도메인 격리 옵션)로 불량 모듈이 핵심 동작을 흔들지 못하게 방지
- 다중 아키텍처 지원: ARM, PowerPC, x86, RISC-V 등
- **VxWorks 7** 세분화 릴리스(SDK, RTOS 커널, 인증 패키지 분리)
- 실시간 프로세스·스레드 모델, SMP 지원

---

## 3. 왜 항공·방산·의료에서 선택되는가

| 요구 | VxWorks 대응 |
|---|---|
| 마이크로초级 결정성 | 모놀리식 RT 커널, 예측 가능한 컨텍스트 스위칭 |
| 인증 일정 단축 | **OS 인증 산출물**( 요구사항 추적 매트릭스, 검증 테스트 결과 ) 사전 취득 |
| 방사선/极端 환경 | 우주용 검증 이력(화성 로버 등) |
| 장기 공급 | 10년+ 유지보수 라이선스, EOL 관리 |
| 검증 도구 | 시뮬레이터, 하드웨어 인 더 루프(HIL), 형상 관리 체계 |

> **중요**: "인증 산출물 제공"은 OS 자체의 인증 상태를 뜻합니다. **최종 제품(항공기·장비) 인증은 OEM이 별도로** 받아야 하며, OS 인증은 그 과정의 입력 자료일 뿐입니다.

---

## 4. 단점

- 고가의 독점 상용 라이선스 → 취미/저마진 소비자 전자제품에는 비현실적
- 커스텀 기능·드라이버가 **Wind River의 폐쇄적(Vendor Lock-in) 생태계**에 종속
- 팀 인력풀이 오픈소스(RTOS/Linux) 대비 좁음

---

## 5. 대표 적용 사례

- **NASA Mars Perseverance 로버** (JPL 임무 컴퓨터)
- **Boeing 비행제어 컴퓨터** 등 상용 항공전자
- 상용 **MRI 장비**
- **철도 제어 시스템**, **고속철도 신호 장비**
- 방산: 레이다, 전자전, 무인 시스템

---

## 6. QNX·FreeRTOS와의 위치

| 항목 | FreeRTOS | VxWorks | QNX |
|---|---|---|---|
| 커널 | 소형 선점형 | 모놀리식 RT | 마이크로커널 |
| 비용 | 무료 | 고가 상용 | 고가 상용 |
| 인증 산출물 | 제한적 | DO-178C/IEC 61508/ISO 26262 | ISO 26262 ASIL D 등 |
| 결함 격리 | 약함 | 커널 내 보호 | 프로세스 격리(탁월) |
| 주력 분야 | IoT/산업 | 항공·우주·방산·의료·철도 | 자동차 콕핏·ADAS |

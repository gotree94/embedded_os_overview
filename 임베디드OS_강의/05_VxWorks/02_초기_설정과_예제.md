# VxWorks — 초기 설정과 예제

> 7일차 실습 (120분) · Wind River 계정 + VxWorks 7 for QEMU

> 상용 라이선스가 필요하므로, 교육용으로는 **무료 평가 환경**(Wind River GitHub의 공개 포트/샘플 + QEMU) 또는 강사 준비 환경을 사용합니다.
> 최신 절차: Wind River Developer Community (support.windriver.com) 문서 우선 확인.

---

## 1. 사전 준비

1. **Wind River 계정** 등록 (무료 평가용 다운로드·라이선스 발급 대상 확인)
2. 다운로드:
   - VxWorks 7 Source/BSP 패키지
   - VxWorks Quick Start 또는 이미지(공개 포트: `vxworks7` 관련 저장소)
   - QEMU (vxqemu) 또는 실물 보드 BSP
3. 호스트: Linux(x86_64) 또는 Windows + WSL2. RAM 16GB 이상 권장.

## 2. 환경 구성 (Linux 예시)

```bash

  libglib2.0-dev libpixman-1-dev
```

Wind River가 제공하는 공개 포트/예제 저장소를 클론(예시):

## 3. QEMU에서 부팅 확인

평가 이미지가 준비되면(ximg/elf):
```bash
qemu-system-x86_64 -m 512 -nographic -kernel <vxworks-image>
```

또는 Wind River 제공 스크립트:
```bash
make qemu        # 저장소의 Makefile에 따라
```

부팅 로그 예시:
```
VxWorks 7 (QEMU x86_64)
Copyright Wind River Systems, Inc.
->                                 ← 셸 프롬프트
```

`->` 셸에서 확인:
```
i                    /* 태스크/디바이스 열거 */
devs
sp myRoutine         /* 임무 루틴을 태스크로 스폰 */
```

## 4. 예제 1. 태스크 생성과 우선순위 (실습 셸)

VxWorks 셸(VSB/VTP 셸) 명령:
```
/* 태스크 함수를 스폰 (우선순위, 스택, 옵션) */
sp myTask, 200, 0, 0, 0x8

/* 태스크 목록 */
i

/* 태스크 중지 */
taskSuspend myTask0
```

C 코드(임무 태스크 예시):
```c
LOCAL void myTask (int param)
{
    while (1) {
        /* 센서 읽기 → 제어 → 출력 */
        taskDelay (sysClkRateGet() / 10);   /* 100ms 주기 */
    }
}
```

## 5. 예제 2. 인터럽트 루틴과 락 (개념 코드)

```c
STATUS sysMemSampleInit (void)
{
    if ((semCCreate (&memLock, SEM_Q_PRIORITY, SEM_FULL)) == NULL)
        return ERROR;
    return OK;
}

void memIsr (void)
{
    semGive (memLock);      /* ISR에서는 락 해제/신호만 */
}
```

- VxWorks의 **intConnect()** 로 ISR 등록
- ISR과 태스크 간 동기화: 세마포어/큐/이벤트 플래그
- FreeRTOS의 `xQueueSendFromISR` 패턴과 개념 동일

## 6. 예제 3. 인증 프로젝트 워크플로 (이론 실습)

DO-178C 항공기 프로젝트에서 OS 활용 흐름:

```
1. 소프트웨어 수준 요구 정의 (SOR)
2. Wind River 인증 산출물 패키지 수령
   - 인증 계획(CP), 요구사항 추적, 검증 결과, 커버리지 보고
3. OEM의 전체 시스템 인증 계획에 OS 자산 편입
4. 임무 소프트웨어 요구 → OS 인터페이스 추적
5. HIL 테스트 + 독립 검증(IV&V)
6. 당국(ATC/EASA 등) 제출
```

수업 실습: 본인 팀 프로젝트(예: 드론 비행제어)에 대해
- 어떤 OS 인증 자산이 필요한가 목록화
- "OS 인증 ≠ 제품 인증"임을 근거 자료로 정리

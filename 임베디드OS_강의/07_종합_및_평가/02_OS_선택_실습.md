## 워크시트 B. 하이브리드 아키텍처 설계

제품 3번(트랙터)을 **Linux + MCU RTOS 혼합**으로 재설계하세요.

```
[ AP: Embedded Linux ]            [ MCU: FreeRTOS / Zephyr ]
  - 카메라 영상 처리                     - GPS/IMU 샘플링 (100Hz)
  - 지도·경로 UI                         - 차동구동 제어 루프 (10Hz, 결정적)
  - OTA·로그 업로드                     - 비상 정지 (인터럽트 직결)
        ↕ 통신 (UART/CAN/이더넷)
```

제출물: 각 영역의 주기·실시간 등급·실패 시 영향 표.

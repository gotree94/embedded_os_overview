## 2. 진화 관점 요약

```
복잡도 ↑   Bare Metal → FreeRTOS → Zephyr → VxWorks / QNX
                                ↘ Embedded Linux (AP·GUI·생태계)
```

- **제어 중심** → RTOS 계열 (결정성·안전)
- **서비스·UX 중심** → Linux 계열 (생태계)
- **안전 필수** → 상용 인증 RTOS (VxWorks/QNX)

---

## 3. 각 OS 한 줄 요약

| OS | 한 줄 요약 |
|---|---|
| **Bare Metal** | 가장 가볍고 빠르지만 복잡해지면 감당 불가 |
| **FreeRTOS** | 작고 널리 쓰이는 MCU RTOS, 스택은 직접 조립 |
| **VxWorks** | 항공·방산·의료용 상용 Hard RT, 인증 산출물 강점 |
| **Embedded Linux** | 풍부한 생태계, 대신 무겁고 Soft RT |
| **Zephyr** | 표준화·프로토콜 스택 내장·이식성, 학습 곡선이 높음 |
| **QNX** | 마이크로커널 결함 격리, 자동차 안전의 강자 |

---

## 4. 기억해야 할 6가지 핵심 문장

1. Bare Metal의 위험은 **'한 함수가 멈추면 시스템 전체가 멈춘다'**.
2. FreeRTOS의 약점은 **'기본 메모리 보호가 없다'**.
3. VxWorks의 무기 = **Hard RT + 인증 산출물**.
4. Embedded Linux = **생태계**, 대가로는 **부팅 시간·비결정성**.
5. Zephyr = **Device Tree + Kconfig + 통합 프로토콜 스택**.
6. QNX = **마이크로커널 결함 격리**, 자동차 ASIL D.

# 기말 평가

## Part 1. 필기 평가 (40점)

### 서술형 (20점, 각 4점)

1. Bare Metal에서 모든 주변장치를 Non-blocking으로 설계해야 하는 이유를, ISR·메인 루프 관점에서 설명하시오.

2. FreeRTOS와 Zephyr의 하드웨어 기술 방식 차이(Device Tree 유무 포함)를 비교하고, 이 차이가 이식성에 미치는 영향을 설명하시오.

3. Embedded Linux의 실시간성 한계와 `PREEMPT_RT`, 그리고 MCU+RTOS 혼합 구조가 등장하는 이유를 연결지어 설명하시오.

4. VxWorks와 QNX 모두 상용 임무 필수 RTOS이나 강점 분야가 다릅니다. 커널 구조 차이에서 도출되는 이유를 설명하시오.

5. 다음에 적합한 OS를 고르고 각각 근거 2가지를 적으시오.
   - (a) 전동칫솔  (b) Nordic nRF53 기반 Matter 스마트 조명
   - (c) 차량 디지털 콕핏  (d) EV 충전기 터치 단말

### 서술형 답안 요지

1. Super Loop에서 한 함수가 블로킹되면 **루프 전체가 멈춰** 다른 기능이 정지. ISR은 짧게 처리하고 실제 작업은 루프에서 플래그/큐 기반으로 수행해야 한다.

2. FreeRTOS는 핀·기능 설정이 코드/`FreeRTOSConfig.h`에 직접 기술, Zephyr는 **Device Tree(하드웨어)와 Kconfig(기능)**로 분리 선언. → Zephyr는 보드 교체 시 앱 코드 불변, 다중 보드 이식성 우수.

3. 기본 커널은 Soft RT/비결정적 → PREEMPT_RT 패치로 개선 가능하지만, 여전히 마이크로초 확률 지연이 필요하면 **제어 루프는 MCU+RTOS, 서비스·UI는 Linux**로 분리하는 혼합 구조가 비용·성능·안정성에서 유리.

4. VxWorks는 **모놀리식 RT 커널**로 항공·우주·철도·의료에서 결정성과 인증 산출물이 강점. QNX는 **마이크로커널로 프로세스 격리**가 탁월해 자동차 콕핏·ADAS에서 ASIL D와 결함 격리가 강점.

5. (a) Bare Metal — 단순·저비용·저전력. (b) Zephyr — Matter/Thread/BLE 스택 내장, nRF 공식 지원. (c) QNX — ASIL D·결함 격리. (d) Embedded Linux — 터치 GUI·네트워크·DB·OTA 생태계.

### 서술형 채점 루브릭

| 등급 | 기준 |
|---|---|
| 우수(4) | 개념 정확 + 근거 연결 + 예시 인용 |
| 보통(2~3) | 핵심 언급, 연결 미흡 |
| 미흡(0~1) | 오개념 또는 부분 답 |

## Part 2. 미니 프로젝트 (60분, 팀당)

**A. 요구사항 기반 OS 선정·설계서**

- 또는 Embedded Linux 이미지에 서비스를 등록해 재시작 복구 시연

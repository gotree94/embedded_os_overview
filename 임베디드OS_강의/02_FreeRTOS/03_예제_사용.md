> 4일차 실습 (120분) · Bare Metal 때 만든 센서/로깅 구조를 태스크로 재설계

## 예제 1. 태스크 생성과 독립 점멸 (20분)

```c
#include "FreeRTOS.h"
#include "task.h"

#define LED1_PIN  GPIO_PIN_12
#define LED2_PIN  GPIO_PIN_13

static void vBlinkTask(void *pv)
{
    TickType_t last = xTaskGetTickCount();
    const TickType_t period = pdMS_TO_TICKS(500);
    for (;;) {
        HAL_GPIO_TogglePin(GPIOD, LED1_PIN);
        vTaskDelayUntil(&last, period);   // 주기 보장 (vTaskDelay와 차이 주의)
    }
}

static void vSlowBlinkTask(void *pv)
{
    for (;;) {
        HAL_GPIO_TogglePin(GPIOD, LED2_PIN);
        vTaskDelay(pdMS_TO_TICKS(1500));
    }
}

/* main.c */
int main(void)
{
    HAL_Init(); SystemClock_Config(); MX_GPIO_Init();

    xTaskCreate(vBlinkTask,     "led1", 128, NULL, 2, NULL);
    xTaskCreate(vSlowBlinkTask, "led2", 128, NULL, 1, NULL);
    vTaskStartScheduler();
    for (;;) {}   // 도달하지 않음 (메모리 부족 시 여기로 복귀)
}
```

**관찰**: 두 LED 주기가 독립적임을 확인. Bare Metal의 `HAL_Delay(1500)`이면 다른 작업이 1.5초간 멈췄을 것입니다.

## 예제 2. 큐로 ISR → 태스크 통신 (30분)

가속도 센서 인터럽트(가상)의 값을 태스크로 전달합니다.

```c
QueueHandle_t xAccelQueue;

typedef struct { int16_t x, y, z; uint32_t t; } sample_t;

void EXTI15_10_IRQHandler(void)
{
    BaseType_t hp = pdFALSE;
    sample_t s = { .x = read_ax(), .y = read_ay(), .z = read_az(),
                   .t = HAL_GetTick() };

    xQueueSendFromISR(xAccelQueue, &s, &hp);
    portYIELD_FROM_ISR(hp);          // 높은 우선순위 태스크가 깨어났으면 즉시 전환
}

static void vConsumerTask(void *pv)
{
    sample_t s;
    for (;;) {
        if (xQueueReceive(xAccelQueue, &s, portMAX_DELAY) == pdTRUE) {
            // 블록 중: CPU 점유 0, 다른 태스크가 실행 중
            log_sample(&s);
        }
    }
}

/* init */
xAccelQueue = xQueueCreate(16, sizeof(sample_t));
xTaskCreate(vConsumerTask, "consumer", 256, NULL, 3, NULL);
```

## 예제 3. Mutex로 공유 자원 보호 (20분)

UART를 로깅 태스크와 통신 태스크가 공유할 때:

```c
MutexHandle_t xUartMutex;

void safe_print(const char *msg)
{
    xSemaphoreTake(xUartMutex, portMAX_DELAY);
    HAL_UART_Transmit(&huart2, (uint8_t *)msg, strlen(msg), 100);
    xSemaphoreGive(xUartMutex);
}
```

- `portMAX_DELAY` 대신 `pdMS_TO_TICKS(50)`을 쓰면 타임아웃 후 포기 가능(디드락 완화)
- **우선순위 상속**: 낮은 우선순위 태스크가 뮤텍스를 쥔 채 대기 중 높은 태스크가 필요 시 우선순위가 임시 상승 → 우선순위 역전 방지

## 예제 4. 이벤트 그룹 (20분)

"센서 준비 + 네트워크 연결" 두 조건이 모두 만족할 때 시작:

```c
EventGroupHandle_t xSysEvents;
#define EVT_SENSOR   (1 << 0)
#define EVT_NETWORK  (1 << 1)

/* 각 태스크에서 */
xEventGroupSetBits(xSysEvents, EVT_SENSOR);
xEventGroupSetBits(xSysEvents, EVT_NETWORK);

/* 시작 태스크 */
EventBits_t bits = xEventGroupWaitBits(xSysEvents,
        EVT_SENSOR | EVT_NETWORK,
        pdFALSE,          /* ClearOnExit = FALSE */
        pdTRUE,           /* WaitForAll = TRUE (AND) */
        portMAX_DELAY);
if ((bits & (EVT_SENSOR | EVT_NETWORK)) == (EVT_SENSOR | EVT_NETWORK))
    start_application();
```

## 예제 5. 소프트웨어 타이머와 유휴 훅 (15분)

```c
TimerHandle_t xWatchdogTimer;

void vWatchdogCb(TimerHandle_t t)
{
    feed_hw_watchdog();       /* 타이머 서비스 태스크 컨텍스트에서 실행! */
}

xWatchdogTimer = xTimerCreate("wd", pdMS_TO_TICKS(1000),
                              pdTRUE, NULL, vWatchdogCb);
xTimerStart(xWatchdogTimer, 0);

/* 저전력: 유휴 훅 */
void vApplicationIdleHook(void)
{
    __WFI();   // 인터럽트 대기로 전력 절감
}
```

> **주의**: 타이머 콜백과 Idle Hook은 짧아야 합니다. 무거운 일은 태스크로 옮기세요.

# FreeRTOS — 초기 설정

> 3일차 실습 준비 (60분) · 두 가지 경로 제공: STM32CubeMX / ESP32 Arduino

---

## 경로 A. STM32CubeMX + FreeRTOS (권장, STM32 보드 보유 시)

### A-1. 프로젝트 생성

1. STM32CubeIDE에서 **New STM32 Project** → 보드 선택 (예: Nucleo-F401RE)
2. **Middlewares → ST → FreeRTOS** 선택 → Interface: CMSIS_V1 또는 CMSIS_V2 (V2 권장)
3. FREERTOS 설정 탭에서 아래 최소 옵션 확인:
   - `configTOTAL_HEAP_SIZE`: 예 `0x2000` (8KB) — 보드 RAM에 맞게
   - `configMINIMAL_STACK_SIZE`: `128` (단위: 워드)
   - `configUSE_PREEMPTION`: `1`
   - `configUSE_MUTEXES`: `1`
   - `configUSE_TRACE_FACILITY` / `configUSE_STATS_FORMATTING_FUNCTIONS`: 디버깅 시 `1`
4. **SYS → Timebase Source**: **SysTick 대신 TIM** (FreeRTOS가 SysTick을 쓰므로 충돌 방지)
   - 예: TIM2, 주파수 84MHz → 1ms
5. GPIO/UART 등 주변장치 설정 후 **GENERATE CODE**

### A-2. 생성 구조 확인

```
Core/
├── Src/
│   ├── main.c              # osKernelInitialize(); ... 태스크 생성; osKernelStart();
│   └── freertos.c          # App 콜백: MX_FREERTOS_Init (태스크/큐 여기서 생성)
Middlewares/Third_Party/FreeRTOS/Source/   # 커널 소스
```

태스크 생성은 보통 `App_freertos.c` / `freertos.c`의 `MX_FREERTOS_Init()`에서:
```c
osThreadNew(sensorTask, NULL, &sensor_attr);
```

### A-3. 검증

1. 기본 태스크에서 LED 토글 + `vTaskDelay` → 점멸 주기 정확 확인
2. **FreeRTOS+Trace** 또는 SWO 로깅이 가능하면 태스크 전환 관찰

## 경로 B. ESP32 (Arduino IDE 또는 ESP-IDF)

### B-1. Arduino IDE 경로 (빠른 입문)

1. Arduino IDE → **파일 → 환경설정 → 보드 매니저 URL**에 Espressif 추가:
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. **보드 매니저**에서 `esp32` 설치 → 보드: **ESP32 Dev Module** 선택
3. 기본 예제: **File → Examples → FreeRTOS -> Basic Multi Threading Blinky** 열기
4. 업로드 후 시리얼 모니터에서 두 LED가 독립적으로 점멸하는 것 확인

```cpp
TaskHandle_t Task1;

void Task1code(void *pvParameters) {
  for (;;) {
    digitalWrite(2, HIGH); delay(500);
    digitalWrite(2, LOW);  delay(500);
  }
}

void setup() {
  pinMode(2, OUTPUT);
  xTaskCreatePinnedToCore(Task1code, "Task1", 10000, NULL, 1, &Task1, 0);
}

void loop() { vTaskDelay(1000); }  // loop도 하나의 태스크
```

### B-2. ESP-IDF 경로 (실무)

```
idf.py set-target esp32
idf.py menuconfig   → Component config → FreeRTOS → Tick rate 1000Hz 등
idf.py build flash monitor
```

## `FreeRTOSConfig.h` 핵심 옵션速記표

| 매크로 | 의미 | 권장 시작값 |
|---|---|---|
| `configUSE_PREEMPTION` | 선점형 스케줄러 사용 | 1 |
| `configCPU_CLOCK_HZ` / `configTICK_RATE_HZ` | CPU 클럭 / tick 주기 | 보드 값 / 1000 |
| `configTOTAL_HEAP_SIZE` | 동적 할당 힙 총량 | RAM의 1/4 정도 |
| `configMINIMAL_STACK_SIZE` | 최소 스택 (워드 단위) | 128 (Cortex-M) |
| `configCHECK_FOR_STACK_OVERFLOW` | 스택 오버플로 검사 | 2 (방법 2) |
| `configUSE_MUTEXES` / `configUSE_COUNTING_SEMAPHORES` | 뮤텍스/세마포어 | 1 |
| `configUSE_TIMERS` | 소프트웨어 타이머 | 1 |
| `configUSE_IDLE_HOOK` / `configUSE_TICK_HOOK` | 훅 | 저전력=1 |
| `INCLUDE_vTaskDelete` 등 | 사용 API 포함 여부 | 필요한 것만 |
| `configASSERT(x)` | 런타임 어서트 | 항상 정의 |

> **팁**: `configCHECK_FOR_STACK_OVERFLOW 2`로 두고 `vApplicationStackOverflowHook`에서 UART로 태스크명을 출력하면 스택 사고 디버깅이 훨씬 빨라집니다.
